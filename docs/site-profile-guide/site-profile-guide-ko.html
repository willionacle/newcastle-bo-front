상품 구성

시스템 설정 > 상품 구성  ·  /system/site-profile

1. 이 페이지의 용도

상품 구성은 사이트에서 운영할 게임 상품을 정하는 페이지입니다. 상품은 카지노, 슬롯, 스포츠, 미니게임, 스페셜 게임 5가지이며, 각각 개별로 켜고 끌 수 있습니다.

상품을 끄면:

  • 플레이어 사이트: 해당 상품이 메뉴와 홈 화면에서 사라져 플레이어가 더 이상 찾을 수 없습니다.
  • 백오피스: 해당 상품의 메뉴와 탭이 숨겨져, 실제 운영 중인 상품만 표시됩니다.

2. 페이지 여는 방법

  1. 백오피스에 로그인합니다.
  2. 왼쪽 메뉴에서 시스템 설정을 엽니다.
  3. 상품 구성을 클릭합니다.

3. 화면 구성

항목설명
1현재 프리셋현재 적용된 구성을 표시합니다: 스포츠 + 카지노, 카지노 전용, 커스텀.
2프리셋 버튼원클릭 설정 버튼입니다. 클릭하는 즉시 저장됩니다.
3상품 스위치 (5개)상품별 켜기/끄기. 수정을 눌러야 변경할 수 있습니다.
4수정 / 취소 / 저장스위치 잠금 해제, 변경 취소, 변경 저장. 페이지 오른쪽 위에 있습니다.

4. 프리셋으로 빠르게 설정하기

  1. 스포츠 + 카지노 또는 카지노 전용을 클릭합니다.
  2. "상품 구성이 업데이트되었습니다." 메시지를 확인합니다.
  3. 현재 프리셋과 스위치가 새 구성으로 바뀌었는지 확인합니다.
주의 프리셋 버튼은 누르는 즉시 저장됩니다. 저장 단계나 확인 창이 없으니 신중하게 클릭하세요.

5. 상품 개별 설정하기

  1. 오른쪽 위 수정을 클릭합니다. 스위치 잠금이 풀립니다.
  2. 상품별 스위치를 켜거나 끕니다.
  3. 저장을 클릭합니다. 변경을 되돌리려면 취소를 클릭합니다.
  4. "상품 구성이 업데이트되었습니다." 메시지를 확인합니다.
"커스텀"이란? 스위치 조합이 어느 프리셋과도 일치하지 않으면 현재 프리셋이 커스텀으로 표시됩니다. 정상입니다.

6. 백오피스에서 달라지는 점

꺼진 상품숨겨지는 항목
스포츠스포츠 관리자 설정 메뉴, 베팅 관리 > ITF 경기/배당 목록. 게임·베팅 페이지의 스포츠 탭.
스페셜 게임스페셜 게임 관리 메뉴. 게임·베팅 페이지의 스페셜 탭.
카지노, 슬롯, 미니게임게임·베팅 페이지의 해당 탭.

전체 탭은 항상 표시됩니다.

7. 플레이어 사이트에서 달라지는 점

꺼진 상품플레이어 화면
카지노카지노 메뉴가 사라집니다. 홈 화면과 사이드 메뉴의 카지노 배너도 사라집니다.
슬롯슬롯 메뉴가 사라집니다. 홈 화면과 사이드 메뉴의 슬롯 배너도 사라집니다.
미니게임미니게임 메뉴가 사라집니다.
스포츠스포츠 메뉴가 사라집니다.

켜져 있는 상품은 영향을 받지 않습니다. 예: 슬롯만 끄면 카지노 배너는 그대로 표시됩니다.

변경이 적용되는 시점 로그인한 플레이어는 페이지를 새로고침하거나 다시 로그인하면 변경 사항이 보입니다. 로그인하지 않은 방문자에게는 모든 메뉴가 그대로 표시됩니다. 메뉴는 로그인 후에만 적용됩니다.

8. 참고 사항

  • 숨김은 삭제가 아닙니다. 상품을 끄면 메뉴와 탭만 숨겨지고, 기존 데이터와 기록은 그대로 유지됩니다.
  • 메뉴가 바뀌지 않나요? 페이지를 새로고침(F5)하세요.
  • 일부 저장 실패: 일부 상품이 저장되지 않으면 빨간 메시지에 해당 상품이 표시됩니다. 스위치를 확인하고 다시 시도하세요.
  • 저장 실패: 네트워크를 확인하고 다시 시도하세요. 계속 실패하면 개발팀에 문의하세요.
