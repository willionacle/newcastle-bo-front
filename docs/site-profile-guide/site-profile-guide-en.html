Back Office Guide

Product Profile

System Settings > Product Profile  ·  /system/site-profile

1. What this page is for

Product Profile decides which game products your site runs. There are five products: Casino, Slot, Sports, Minigame and Special Games. Each one has its own on/off switch.

When a product is turned off:

  • Player site: the product disappears from the menus and home screen, so players can no longer find it.
  • Back office: its menus and tabs are hidden, so staff only see what the site actually sells.

2. How to open the page

  1. Log in to the back office.
  2. In the left menu, open System Settings.
  3. Click Product Profile.

3. Parts of the page

PartWhat it does
1Current presetShows which setup is active: Sports + Casino, Casino Only or Custom.
2Preset buttonsOne-click setups. They save immediately.
3Product switches (5)Turn each product on or off. Locked until you click Edit.
4Edit / Cancel / SaveUnlock the switches, discard changes, or save changes. Top-right of the page.

4. Quick setup with a preset

  1. Click Sports + Casino or Casino Only.
  2. Wait for the message "Product profile updated."
  3. Check that Current preset and the switches now show the new setup.
Heads up Preset buttons save right away. There is no Save step and no confirmation. Click only when you mean it.

5. Turn products on or off one by one

  1. Click Edit at the top right. The switches unlock.
  2. Turn each product switch on or off.
  3. Click Save. To undo your changes instead, click Cancel.
  4. Wait for the message "Product profile updated."
About "Custom" If your switches don't match either preset, the current preset shows Custom. This is normal.

6. What changes in the back office

When this is OFFWhat gets hidden
SportsSports Admin Controls menu, and Betting Management > ITF Games/Odds List. Sports tabs on game and betting pages.
Special GamesSpecial Games menu. Special tabs on game and betting pages.
Casino, Slot, MinigameTheir tabs on game and betting pages.

The All tab is always shown.

7. What changes on the player site

When this is OFFWhat players see
CasinoCasino menu is removed. The casino banner on the home screen and side menu is removed.
SlotSlot menu is removed. The slot banner on the home screen and side menu is removed.
MinigameMinigame menu is removed.
SportsSports menus are removed.

Products that stay on are not affected. For example, if only Slot is off, the Casino banner still shows.

When players see the change Players who are logged in see the change after they refresh the page or log in again. Visitors who are not logged in still see every menu. Menus are only filtered after login.

8. Good to know

  • Hiding is not deleting. Turning a product off hides its menus and tabs. Past data and records are kept.
  • Menu not updated? Refresh the page (F5).
  • Partial save error: if some products could not be saved, a red message names them. Check the switches and try again.
  • Save failed: check your connection and try again. If it keeps failing, contact the developer.
